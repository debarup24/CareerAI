# CareerAI - AI Powered Career Assistant Platform

**CareerAI is a fullstack AI-powered MERN application designed to help users improve their career journey with intelligent resume analysis, ATS optimization & ATS score, interview preparation with resume based interview questions, ATS friendly AI resume generation and job role matching.**

Built using **MERN Stack**, integrated with **AI APIs (Gemini)**, secured authentication with **Google OAuth** and powered with secure payment integration using **Razorpay**, deployed on **Render**

---

# Features :

## 📄 1. Resume Analyzer

Users can:

- Upload their resume PDF or manually input resume details
- Get AI-powered resume analysis
- Receive an overall ATS score
- Get section-wise scoring including:
  - Formatting
  - Keywords
  - Skills
  - Experience
  - Readability
- Receive detailed suggestions for improvement
- Download the complete analysis report as PDF

---

## 🎯 2. Job Matcher

Users can:

- Upload resume or manually enter skills & experience
- Get AI-generated suggestions for suitable job roles with a match score
- Understand which industry roles best fit their profile
- Receive role recommendations based on:
  - Skills
  - Experience
  - Resume content
  - Tech stack

---

## 📝 3. AI Resume Builder

Users can:

- Generate stunning ATS-friendly resumes using AI
- Create resumes by providing required details
- Improve existing resumes by uploading old resume PDFs
- Download generated resumes instantly

---

## 🎓 4. Interview Preparation

Users can:

- Upload resume or provide skills & experience
- Get AI-generated interview questions
- Receive:
  - Technical Questions
  - HR/Behavioral Questions
- Get hints and preparation guidance
- Download interview questions as PDF

---

## 💳 5. Subscription & Payments

- First **5 AI requests are free**
- Users can upgrade their plan any time
- Integrated with **Razorpay Payment Gateway**
- Secure payment handling

# 🔑 Environment Variables

Create a `.env` file inside the backend folder and add:

```
PORT=5000

MONGO_URI=YOUR_MONGODB_URI

JWT_SECRET=YOUR_SECRET_KEY

GOOGLE_CLIENT_ID=YOUR_GOOGLE_CLIENT_ID
GOOGLE_CLIENT_SECRET=YOUR_GOOGLE_CLIENT_SECRET

GEMINI_API_KEY=YOUR_API_KEY

RAZORPAY_API_KEY=YOUR_API_KEY
RAZORPAY_KEY_SECRET=YOUR_KEY_SECRET
```
